name: new-subcrew
description: Retired. Builder no longer uses child sessions under a crew. Use when someone asks for a child session, a sub-session, or a second session nested under a crew, so the request goes to new-crew instead. Never create a child session.
---

**Builder no longer uses child sessions.** Do not create a session nested under a crew, and do not
add an entry to a crew spec's `sessions` array.

A second session for the same work is a crew of its own, made by the steward with `new-crew`. Ask
the steward for one, saying what the session is for and which crew's work it continues. Grouping
related crews on Deck's rail is Deck's own feature, set in Deck, and does not depend on how
sessions are named or where their directories are.

If the person asking insists on a child session, tell them it is retired and that `new-crew` makes
the crew instead. Change nothing.
